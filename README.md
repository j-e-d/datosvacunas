> **Proyecto archivado.** El [Monitor Público de Vacunación] dejó de actualizarse el 3 de octubre de 2026 y los archivos de descarga del Ministerio de Salud ya no están disponibles. Los datos de este repositorio llegan hasta esa fecha y no se actualizarán más.

El bot [@cuantaVacunaAr]  utilizaba los datos de vacunas aplicadas del archivo [vacunas.csv](vacunas.csv). El mismo se bajaba automáticamente cuando se actualizaba el [Monitor Público de Vacunación], lo que ocurría habitualmente a las 6 y a las 18 horas.

Los datos de población usados para calcular porcentajes son los mismos que utiliza [Covidstats] y corresponden a la [Población estimada a julio 2020 por INDEC].

En el archivo [Covid19VacunasAgrupadas.csv](Covid19VacunasAgrupadas.csv) se guardó la publicación diaria de los [datos del Ministerio de Salud] hasta que dejaron de estar disponibles.
